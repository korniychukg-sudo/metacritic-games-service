# Переписка с нейросетью

Сервис собран в Claude Code (модель Claude Opus) не одним длинным чатом, а конвейером агентов. У каждого агента
чистый контекст и одна роль, а его работу проверяет другой агент. Агентов запускали скрипты-оркестраторы
([workflows/](workflows/)): они подставляют в промпт текст задания, общие правила и отчёт предыдущего этапа.
Я ставил задачу и требования к результату и принимал решения по находкам ревьюеров; скрипты-оркестраторы
с промптами для агентов генерировались вместе с ИИ, промпты в них на английском. Интерфейс и документация
сервиса на русском.

Почему так: в длинном чате модель к концу забывает требования и начинает хвалить собственную работу. Отдельный
ревьюер с чистым контекстом находит то, что автор пропустил, а его находки проверяет ещё один агент.

повторяется до трёх раз.

## Общие правила в каждом промпте

- работать только в папке проекта, зависимости закреплены;
- вежливо к Metacritic и YouTube: не больше запроса в секунду, повторы с паузой, образцы ответов сохраняются,
  а не запрашиваются снова;
- бесплатная LLM без ключа; если она не ответила, карточка всё равно заполняется резюме из цитат с пометкой метода;
- не деплоить, не пушить, не хранить секреты, сервис работает без них;
- никогда не ждать часовой планировщик по реальным часам: расписание и смену дня проверять тестами с подменёнными
  часами (правило появилось после того, как первый ревьюер час ждал следующего запуска).

## Где ИИ ошибался и как это поймали

- **Летсплей другой игры.** Первая версия брала Space Marine 2 для Boltgun 2 и Planet Zoo для Planet Zoo 2.
  Поймано живым прогоном; название ролика стало обязано содержать подзаголовок и номер части.
- **Летсплей другой игры, второй раз.** Сравнение названий осталось «набором слов», и на сотне свежих инди-игр
  с короткими названиями треть заключений оказалась о других играх: Rock Hunter получила 11-летний летсплей
  Monster Hunter («Let's ROCK Basarios»), HAUNT — Super Mario 64 («Big Boo's Haunt»), Bathyscaphe — польский
  летсплей GTA 5, который поиск YouTube машинно перевёл как «Theft of the bathyscaphe». LLM при этом уверенно
  писала «игра Rock Hunter предлагает интересный геймплей», хотя в её же цитате было «welcome back to Monster
  Hunter». Трейлеры тоже: свадебное видео «ETHAN & VANISHA» и трейлер фильма с Джетом Ли. Нашёл независимый
  агент второго раунда проверки, пройдя карточки живой базы. Теперь название должно стоять фразой
  в оригинальном заголовке, ролик не может быть старше игры больше чем на год, LLM называет игру из расшифровки,
  и код отбрасывает ролик, если это другая игра, а старые записи миграция пересчитала. Первая попытка спросить
  LLM прямо «о той ли игре ролик?» не сработала: бесплатная модель ответила «да» и для Rock Hunter с цитатой
  про Monster Hunter, поэтому вопрос заменили на извлечение названия.
- **Лимит частоты принят за длинный промпт.** Бесплатная LLM на частые запросы отвечает 402, а код урезал промпт
  навсегда. Нашло code review.
- **Ответы по-английски.** Модель иногда отвечала по-английски на английские отзывы; теперь каждый пункт
  проверяется на язык, и запрос повторяется.
- **Выдуманное мнение блогера.** Для ролика без комментариев (только диалоги игры и музыка, в субтитрах
  «Heat. Heat. Heat.») LLM всё равно написала, что «автор ценит производительность на PS5 Pro». Нашли ревьюеры
  требований и интерфейса. Теперь LLM сначала отвечает, звучит ли голос автора, и приводит его дословные цитаты;
  цитаты сверяются с текстом, без них ролик пропускается. Пересказ описания ролика больше не выдаётся за мнение.
- **Не самый популярный ролик.** Если у самого популярного ролика не было субтитров, бралась менее популярная
  запись с субтитрами, хотя Whisper мог распознать первую. Теперь для каждого ролика по порядку просмотров
  сначала субтитры, потом Whisper.
- **Dockerfile ломал деплой на Railway, кнопку запуска можно было нажимать с чужого сайта.** Нашли ревьюеры до сдачи.
- **YouTube блокирует облачные серверы.** Поиск работает, а субтитры и аудио нет («Sign in to confirm you're not
  a bot»). На сервере ролик находится и даётся ссылка с пересказом описания, полная расшифровка включается через
  `YOUTUBE_PROXY_URL`.

## Что в этих файлах и что из них убрано

- Промпт каждого агента приведён дословно, как его получил агент; итоговый ответ агента тоже дословно.
  Ответ последнего этапа агент записал в лог сам перед коммитом и вернул оркестратору тот же текст; хэш
  коммита с самим логом в нём указать нельзя, поэтому там стоит хэш коммита с исправлениями.
  Ход работы показан списком действий (какие команды и файлы), без вывода инструментов.
- Убраны: служебные вставки среды запуска, мои сообщения в основной сессии, не относящиеся к этому заданию,
  ход рассуждений модели, а также локальные пути (заменены на `~`, `[scratchpad]`) и IP-адрес (заменён на `[IP]`;
  адрес 203.0.113.7 в логах — это замена из документационного диапазона, которой он заменён в образцах).
- Скрипты-оркестраторы лежат в [workflows/](workflows/); во втором из них константы `TZ`, `RULES` и `CR`
  (текст задания, правила, отчёт code review) задавались отдельно и совпадают с первым скриптом и логом
  [04-review-code.md](04-review-code.md).
- Перед публикацией история git переписана, чтобы убрать из сохранённых страниц YouTube IP-адрес и идентификаторы
  посетителя, поэтому хэши коммитов, упомянутые в логах, относятся к исходной истории.
